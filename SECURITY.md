# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately, through either channel:

1. **GitHub private vulnerability reporting**: open this repository's Security tab and choose "Report a vulnerability".
2. **Email**: contact@atelierjacquelinesuzanne.fr

Please do not open public issues or pull requests for vulnerabilities, and do not include real secrets (passwords, tokens, API keys) in your report.

## Scope

In scope:

- this repository's website code;
- the `public/contact.php` endpoint;
- the CI and deploy workflows under `.github/`.

Vulnerabilities in third-party services (Sanity, GitHub, OVH) should be reported to those vendors.

## Supported versions

Only the code on the `main` branch and the live site are supported.

## Expectations

This is a small personal project. Reports are handled on a best-effort basis, and there is no bug bounty.
