## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Visitor browser (client-side scroll listener) | This plan adds a client-side `<script>` that reads layout geometry (`getBoundingClientRect`, `matchMedia`) and writes inline styles on the visitor's own page. It takes no external/user/network input, performs no eval, and touches no data. The only boundary is the visitor's own browser acting on its own DOM. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-03-DOS | Denial of Service (main-thread jank) | scoped scroll-driver `<script>` | low | mitigate | Scroll handling is rAF-throttled (single queued frame via `rafId`) and the listener is detached entirely on mobile and reduced-motion via the dual matchMedia gate — bounding main-thread work and preventing runaway scroll handlers. |
| T-15-03-A11Y | Denial of access (motion/no-JS/reduced-motion users) | fallback CSS + `<noscript>` | low | mitigate | Reduced-motion, mobile, and no-JS visitors all receive a correct settled/static end-state via CSS media queries + `<noscript>`, never a blank or broken hero; focus-visible preserved on any new focusable element. Covered by Task 2 + Task 3 assertions. |
| T-15-03-INJ | Tampering (script injection) | scoped inline `<script>` | low | accept | The script is a static, author-controlled module with no dynamic code execution and no external input; it cannot be influenced by CMS data or the visitor. Nothing to mitigate beyond not introducing eval/innerHTML (none is). |
| T-15-SC | Supply chain (npm/pip/cargo) | — | n/a | accept | No package installs — the pin+shrink is dependency-free vanilla JS (UI-SPEC forbids a new animation library). No legitimacy gate applies. |

ASVS L1, block-on-high: no high-severity threats — nothing blocks. Client-only presentational motion on a read-only page; risk profile is trivial and documented.
