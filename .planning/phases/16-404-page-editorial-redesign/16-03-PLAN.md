|----------|-------------|
| Pointer/touch coordinates → client JS state | Live cursor/touch position is read at runtime. It is read-only telemetry: never persisted, never sent over the network, never used to build a DOM string, HTML, or attribute — only reduced to a numeric proximity that selects an interval and toggles a CSS class. No injection sink exists. |
| (no server boundary) | Static page; no request-time compute; no new network call at runtime (all Sanity access remains build-time-only). |
