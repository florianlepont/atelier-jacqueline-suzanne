<objective>
Create the pure, framework-free proximity→interval math module (`src/lib/pop-rate.ts`) that encodes the 404 page's pop-rate speed curve and — critically — the WCAG-adjacent photosensitive-safety cap (D-10). Extracting this math into a standalone module (mirroring `src/lib/image-orientation.ts`'s pure-function shape) is what makes the accessibility ceiling unit-testable in Node without simulating real pointer/touch events in a browser. This is the phase's Wave 0 foundation: the client engine in plan 16-03 imports these exact symbols.

Purpose: Make the load-bearing accessibility cap (D-10) provable by a fast unit test, and give the client engine a single, tested source of truth for the speed curve (D-08) that is identical for mouse pointer and touch (D-09).
Output: `src/lib/pop-rate.ts` + `tests/unit/pop-rate.test.ts`, green under `npx vitest run tests/unit/pop-rate.test.ts`.
</objective>
