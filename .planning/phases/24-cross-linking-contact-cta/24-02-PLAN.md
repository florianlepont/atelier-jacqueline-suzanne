| Build-time URL construction → emitted static HTML | Hrefs must carry the deploy-target base prefix or produce broken navigation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-04 | Tampering | `GalleryDetailModel.relatedLink.text` (editor-authored title interpolated into page copy) | low | mitigate | The title is embedded in a plain template literal and rendered by the body component as a JSX-style expression child, which Astro HTML-escapes automatically. No `set:html` is introduced anywhere in this phase. Upstream, plan 24-01's sanitizer already rejects non-string / empty titles. |
| T-24-05 | Spoofing | `contactCtaHref` destination | low | mitigate | The href is built exclusively by `getRelativeLocaleUrl(locale, 'contact')` against a hardcoded internal route segment — no editor-controlled or user-controlled value reaches it, so the CTA cannot be redirected to an external destination through content. Acceptance criteria grep-pin both call sites. |
| T-24-06 | Denial of Service | Broken navigation under a non-root `base` (GitHub Pages `ASTRO_BASE=/ajs-website/`) | low | mitigate | Both new hrefs route through Astro's base-aware URL builder; CI's existing un-prefixed-link grep guard runs against the Pages build artifact and fails on a literal-path regression. |
| T-24-SC | Tampering | npm / pip / cargo installs | low | accept | This plan installs zero packages (RESEARCH.md Standard Stack: "This phase adds zero dependencies"). Legitimacy gate not applicable. |
