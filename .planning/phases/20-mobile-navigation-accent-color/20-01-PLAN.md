<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sanity Studio content -> build-time HTML data attributes | A Studio-authored `heroColor` key crosses into `dist/*.html` as `data-hero-color`. It is normalised at build time by `normalizeHeroColor()` in `src/lib/site-config.ts`, which returns one of the five fixed `HERO_COLORS` hex constants or `undefined` — an arbitrary string can never pass through. |
| rendered HTML data attributes -> client `style.setProperty()` | The only place this phase writes a content-derived value into CSS. This is the CSS-injection surface named in 20-RESEARCH.md's Security Domain section. |
| `pickRandomGalleryIndex()` return value -> array index | Untrusted only in the sense of being non-deterministic; must never become a selector or attribute string. |
