<objective>
Pre-emptively reconcile the existing Playwright suite with the mobile homepage rewrite, so that the suite is green at every commit of this phase — before, during, and after plan 21-04 retires the carousel/grid below 767px.

Purpose: a survey of the suite found a real collision surface. Phone-width homepage tests fall into two groups: (a) tests that need the site header interactive at scroll position 0 on the homepage, which D-12 will make invisible and non-interactive while the wordmark zoom is playing; and (b) tests that assert behavior of the carousel/grid that phase 21 retires below 767px. Group (a) is fixed with a reduced-motion preamble — D-15 detaches the scroll driver entirely, so the header never enters its hidden state. Group (b) must have its phone-width assertions retired; the replacement coverage lands with the new deck spec in plan 21-04.

Every edit in this plan is green against the CURRENT production code AND green after the phase lands. That property is the point of doing it in wave 1: it removes any red window from the middle of the phase.

Output: five reconciled spec files. No `src/` change whatsoever.
</objective>
