<objective>
Corriger l'instabilité E2E identifiée pendant l'audit du 2026-08-11 : deux tests calculent `naturalWidth / naturalHeight` sur une image Sanity avant qu'elle ait fini de charger (`naturalWidth === 0` produit `NaN`). Les deux passent systématiquement en relance ciblée — c'est une race de synchronisation de test, pas un bug de rendu.

Purpose : suivre exactement le pattern déjà établi dans `edition.spec.ts` (lignes ~299-312) pour le même problème sur un groupe de tuiles — l'adapter aux deux points d'appel single-image concernés, sans toucher au reste.
Output : les deux tests attendent `img.complete && img.naturalWidth > 0` via `expect.poll` avant de lire le ratio.
</objective>
