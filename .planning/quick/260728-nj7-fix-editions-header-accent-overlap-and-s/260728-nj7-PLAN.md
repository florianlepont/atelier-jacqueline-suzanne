<objective>
Fix two real, screenshot-reported, already-root-caused bugs on the deployed Éditions overview header (from quick task 260728-lbh, sketch-012 F1). Both are one-property-value CSS fixes in the single shared component `src/components/EditionsOverviewBody.astro`, which renders both `/editions/` and `/en/editions/`.

Bug 1 — the "É" accent in the h1 overlaps the "Atelier Jacqueline Suzanne" eyebrow line above it. Cause: `.editions-list h1` has `line-height: 0.9` (a ratio below 1.0 shrinks the line box below the font's natural metrics, so the accented capital's diacritic paints outside its line box into the eyebrow row). Measured live at 1440px: 6.5px of overlap. Fix: raise `line-height` to `1.05` (measured +3.5px clean clearance; re-verified at 800px and 1440px). Because it is a ratio, it holds across the fluid `clamp(64px, 9vw, 140px)` sizing at any viewport.

Bug 2 — too much vertical gap between the header and the row list, now that the title is much bigger than pre-260728-lbh. The 80px total gap is `.editions-list__header`'s `margin-bottom: var(--space-2xl)` (48px) plus `.editions-index__row`'s own `padding: var(--space-xl) 0` (32px top). Fix: reduce ONLY the header's `margin-bottom` from `var(--space-2xl)` to `var(--space-lg)` (48px -> 24px), dropping the total gap to 56px. Leave the row padding alone — it is shared inter-row rhythm.

Purpose: correct two visible defects Florian flagged, exactly as diagnosed and live-verified, without altering the approved sketch-012 F1 design in any other way.
Output: one shared component edited — two property values — one commit.
</objective>
