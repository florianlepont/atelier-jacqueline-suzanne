<objective>
Two fixes to the Studio's publication pipeline UI, both fully decided before planning:

1. The bold label and the small grey detail line under each pipeline node visually touch. The cause is not spacing — it is that @sanity/ui's size-zero `Text` lays out a box shorter than the text it paints, so the stylesheet's gap is eaten by overflowing glyphs. The remedy, verified by isolated before/after pixel measurement, is to render those four elements as plain `span`s styled by the same classes.
2. The nothing-has-been-launched-yet framing currently appears twice — once in the panel header subtitle's vicinity and once, in different words, in the bottom pipeline-detail box. The user wants it stated once, in the header, with the bottom box reduced to naming what step 2 is waiting on.

Purpose: three prior quick tasks (ca1, f22, fq3) tuned widths, margins and reserved heights on this exact element without fixing the gap, because the box they were tuning was never the box being painted. This plan changes the element instead of the numbers. The copy change removes the last remaining duplication in the panel.

Output: four markup swaps, one CSS colour declaration, one new optional flag plus two new strings in `resolvePromoteRow()`, one conditional clause in the header subtitle, re-pointed guard tests plus a new markup guard test, green gates, a redeployed Studio, and a human visual confirmation.
</objective>
