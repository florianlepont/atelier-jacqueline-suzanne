<objective>
Fix the WCAG AA color-contrast failure in the automatic accent palette: `--color-on-accent` is stale dark ink (`var(--gray-900)`, `#1A1A1A`) paired with an accent pink that was deliberately darkened to `#D6327C` for legibility against WHITE — giving 3.81:1 where 4.5:1 is required.

Purpose: a newly published gallery ("Trousseau") with no `heroColor` is the first content to reach the automatic-palette fallback in production, turning a previously-unreachable pairing into a live, intermittently-failing accessibility violation (`tests/e2e/accessibility.spec.ts` "/en/ has no serious or critical automated accessibility violations" flakes at roughly 1-in-6 per run via the HOME-16 random starting accent).

Output: one CSS custom property changed in one file, plus deterministic regression coverage that removes the randomness from the failing case so this cannot silently return.
</objective>
