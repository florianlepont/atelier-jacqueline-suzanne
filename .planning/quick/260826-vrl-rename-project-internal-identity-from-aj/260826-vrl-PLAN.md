# Quick Task 260826-vrl: Rename project internal identity to `atelier-jacqueline-suzanne`

## Objective

The GitHub repo was renamed externally (`florianlepont/ajs-website` -> `florianlepont/atelier-jacqueline-suzanne`)
and the local `origin` remote already points at the new URL. Both of those are DONE and out of
scope — do not re-do them. This task updates the now-stale old-name references inside the
repository's own tracked files.

This is not purely cosmetic. `.github/workflows/deploy.yml` sets `ASTRO_BASE` / `EXPECTED_BASE`
to the GitHub Pages project-page base path, which GitHub derives from the repo name
(`https://<owner>.github.io/<repo>/`). Until those two lines change, the staging deploy builds
every asset and link against a path prefix that no longer exists — a fully broken staging site.

**Target name everywhere: `atelier-jacqueline-suzanne`.** The `sanity/` subproject's
`package.json` is already named `atelier-jacqueline-suzanne`, so this also brings root and
subproject into agreement.
