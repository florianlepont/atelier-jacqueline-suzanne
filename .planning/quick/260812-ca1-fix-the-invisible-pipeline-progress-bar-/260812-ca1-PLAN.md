<objective>
Make the Sanity Studio editorial dashboard's publication progress bar visible again by giving `.editorial-dashboard__pipeline-bar` an explicit full width, and lock the fix in with a source-text regression test.

Purpose: the bar is currently invisible on the deployed Studio — Romane sees two floating labels with nothing between them, which she reported as « incompréhensible et complètement cassé ». The root cause is already diagnosed and empirically verified with an isolated browser repro: the bar is `display:flex` with `flex: 1` (flex-basis 0) children inside a Sanity UI `<Stack>` that does not stretch its children, so the container's own width collapses toward zero. Nothing about the pipeline logic, the segment states, or the markup is wrong — only the container's missing width.

Output: a one-declaration CSS change, a unit test guarding it, green typecheck/lint/build gates, and a redeployed Studio.
</objective>
