<objective>
The publish panel renders a static success sentence after a successful publish, telling the editor that content is published and that the site update is now tracked separately. The pipeline visualisation immediately above it already reports both facts, live. The static line is therefore a duplicate, and because `publicationPanelHasBody` counts the success phase as body content, it also drags a divider rule along with it — leaving, once the sentence is gone, a horizontal line above nothing.

Purpose: delete the duplicated status line and its divider trigger together, so the success state ends cleanly at the pipeline it is already described by.

Output: one JSX block and one OR-clause removed from `EditorialDashboard.tsx`, a source-text guard added to the markup test, green gates, and a redeployed Studio awaiting the user's visual confirmation.
</objective>
