What replaces

The scroll-to-open gesture and its overscroll pull-feedback (sketch 007, shipped as quick-260726-obg, then patched for a black-frame bug in quick-260726-qem) are being removed entirely. This hover system — plus the pre-existing clickable title — becomes the carousel's only "there's more here" affordance. No accumulator, no threshold, no decay timer, no footer-visibility tradeoff: navigation only ever happens on a deliberate click, in either the center zone (open) or an edge zone (prev/next).

The cursor system (shared across all 3 variants)

A translucent ring (1.5px hairline border, 14% white fill) at rest in the center zone — deliberately unlabeled by default, reading as a quiet "modern" abstract shape rather than a rounded SaaS affordance. Near an edge it morphs into a pill tinted in the CURRENT gallery's own accent color (reusing --current-accent, already cycling per-gallery on the real site) with a directional arrow — so the same one cursor system carries both meanings, just reshaped, and the arrow's color ties it back to the site's existing per-gallery palette. Toolbar toggle below lets you compare against a labeled variant ("OUVRIR" appears inside the center ring) if a pure abstract shape reads as too quiet.

Edge zone width

Currently 22% of the frame's width on each side — wide enough to reach deliberately without needing pixel precision, narrow enough that the center "open" zone still dominates the photo. Tune live via the zone-width buttons in the toolbar if 22% feels too eager or too stingy.
