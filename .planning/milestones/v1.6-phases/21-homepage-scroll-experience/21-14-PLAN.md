<objective>
Close `21-UAT.md` round-2 gap 5 (`.planning/debug/homepage-scroll-nav-unreachable-at-start.md`): make the navigation hamburger reachable from first paint by removing the header hide plan 21-10 keyed on `data-intro-active`, restoring D-12's hide scope to the wordmark zoom alone — and, in the same plan, resolve the compositional collision that rule existed to avoid, and rebase the spec onto plan 21-13's pinned intro.

Purpose: gap 5 is a one-rule CSS correction with a coupling. The debug session confirms the rule was deliberate, not accidental — plan 21-10's own comment names its reason: "the small top-left header logo would render simultaneously with the new large centred intro logomark". Round-2 UAT overturns the judgment, not the observation. The developer's exact wording is specific about what they need back: "Le hamburger de navigation devrait au moins apparaître au tout début" — the hamburger, at the very start. Nothing in the correction asks for the header's own logomark to return alongside the intro's.

So this plan does both halves. It deletes the wide rule, and replaces it with a much narrower one that suppresses only the header's logomark for the duration of the intro. That gives the developer exactly what they asked for (navigation reachable from arrival, at scroll 0, without scrolling through anything), keeps the visual composition plan 21-10 protected, and keeps `data-intro-active` a live attribute with a real consumer instead of a dead flag.

The coupling the debug session flagged is real and gets sharper, not softer, after plan 21-13: the redesigned logomark now SHRINKS toward roughly 45% of its starting size across the scrub, which lands it much closer to the header logomark's own size than either static beat ever was. Two similarly-sized copies of the same mark in one screen is a more noticeable duplication than one large and one small — which is why this plan sits immediately after the redesign rather than before it, and why the composition call is recorded as a labelled assumption for the real-device check to overrule if the developer disagrees.

This plan also owns the spec rebase for plan 21-13. That is not padding: the `pre-zoom intro beats` describe block asserts against a structure that no longer exists, and the one case in it that codifies gap 5's defect is in the same block. Rewriting both in one pass is how the coverage is guaranteed not to shrink.

Output: two CSS rule changes in `src/components/HomeCarousel.astro`, and a rewritten describe block plus a rewritten header case in `tests/e2e/homepage-scroll-deck.spec.ts`.
</objective>
